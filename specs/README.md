# Tareas de Coquena

LeanSpec organiza trabajo y evidencia. Las reglas funcionales permanecen en ../docs/README.md;
las tarjetas deben enlazar los documentos del área, no replicarlos.
Los entregables grandes están en [docs/milestones](../docs/milestones/M1-servidor-local.md),
no son tarjetas del tablero. Cada tarea enlaza el milestone al que contribuye;
las dependencias entre tareas sí se registran en LeanSpec.

Usar leanspec board y leanspec search <tema> antes de crear una tarjeta.
Crear con leanspec create <nombre>; consultar con leanspec view <spec>.
Actualizar metadatos mediante leanspec update y relaciones mediante leanspec rel.

Los estados reflejan el trabajo: planned, in-progress, complete y archived.
La inicialización no crea entregas ni autoriza implementar. Revisar instrucciones en ../AGENTS.md.
