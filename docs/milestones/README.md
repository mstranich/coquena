# Roadmap

Coquena is delivered through milestones. Each one builds on the previous one.
The milestone documents are currently written in Spanish.

| Milestone | Focus | Status |
| --- | --- | --- |
| [M1](M1-servidor-local.md) | Local server: backends, models, and managed launches | Delivered |
| [M2](M2-gestion-completa.md) | Complete catalog management | Delivered |
| [M3](M3-definiciones-declarativas.md) | YAML recipes, global services, and projects | Delivered in 0.3.0 |
| [M4](M4-experiencia-completa.md) | Terminal interface | Closing in the 0.4.x series |
| [M5](M5-rendimiento.md) | Performance: measure, compare, and tune on local hardware | Planned |

After M5 there are no planned feature milestones: work focuses on fixes,
stability, and the everyday experience.

## Later

These are directions, not commitments. They have no milestone or date yet.

- **Web UI**: comes after M4, because the terminal interface is the priority and also
  works on a remote server.
- **Disk optimizations**: for example, sharing one copy of a model between projects.

The [user guide](../user-guide/README.md) documents what is available today. The
[design documentation](../design/README.md) describes the intended behavior,
including capabilities that are not available yet.
